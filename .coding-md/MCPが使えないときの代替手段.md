# Figma MCP が使えないときの代替手段

MCP で「Rate limit exceeded」が出てデザイン取得ができない場合、次のいずれかで進められます。

---

## 1. Figma REST API を直接叩く

MCP とは別経路なので、レート制限の影響を受けない場合があります。
※ 専用スクリプトは未配置。必要時にClaudeに「figma APIで node を取ってきて」と依頼すれば、トークン受け取り → curl/node fetch でその場で取得します。

### 1-1. Personal access token を発行

1. Figma の Web → 右上のアイコン → **Settings**
2. **Account** → **Personal access tokens**
3. **Create new token** でトークンを作成（スコープで `file_content:read` があれば OK）
4. トークンをコピー（一度しか表示されません）

### 1-2. APIエンドポイント

```
GET https://api.figma.com/v1/files/{fileKey}/nodes?ids={nodeId}
Header: X-Figma-Token: {あなたのトークン}
```

- `fileKey`: URLの `figma.com/design/{fileKey}/...` の部分
- `nodeId`: URLの `?node-id=8001-484` の `8001-484` をそのまま、または `8001:484` に変換

### 1-3. 結果を保存してコーディングに使う

返ってきたJSONを一時ファイルに保存して AI に「この内容でコーディングして」と依頼できます。必要な部分（テキスト・色・余白など）だけ貼り付けてもOK。

---

## 2. Figma 上でコピーして渡す

- **Copy as CSS**: 対象フレームを選択 → 右クリックなどで「Copy as CSS」があればコピー → ここに貼り付け
- **Dev Mode**: 対象を選択 → 右パネルで「Inspect」の値（フォント・カラー・余白など）をメモしてテキストで共有
- **テキストだけ**: デザインの文言（見出し・リード・ボタンなど）をそのまま貼り付け

「このテキストとレイアウトで HTML/SCSS 書いて」と依頼すれば、その内容で実装できます。

---

## 3. スクリーンショットを共有する

- Figma で該当フレームを選択 → スクリーンショットまたはエクスポートで画像を保存
- その画像をチャットに貼り付け

見た目を元にマークアップ・スタイルの案を出します。

---

## 4. MCP の制限が解除されるまで待つ

「Rate limit exceeded, please try again tomorrow」は、時間経過でリセットされることがあります。翌日や、しばらく時間をおいて再度 `get_design_context` を試してください。

---

## まとめ

| 手段                    | 必要なもの        | 手軽さ                 |
| ----------------------- | ----------------- | ---------------------- |
| Figma REST API          | トークン          | 一度設定すれば再利用可 |
| コピー / テキストで共有 | なし              | すぐできる             |
| スクリーンショット      | なし              | すぐできる             |
| MCP 再試行              | なし              | 制限解除後             |

困ったときは **2・3（コピー／スクショ）** が最も手軽。トークンを発行済みなら **1（REST API）** が再利用しやすい。

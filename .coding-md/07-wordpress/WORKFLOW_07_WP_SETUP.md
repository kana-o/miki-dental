# 工程 7: WordPress構築タスク

## ⚠️ 詳細は `wp-setup` Skill に集約済み

このファイルは **Skill 一覧の参照リンク用**として残しています。実際の手順は `~/.claude/skills/wp-setup/SKILL.md` を参照してください。

## このファイルに残す情報

- Skill 側に書ききれない、プロジェクト固有のメモがある場合のみここに追記
- 例: 特殊な ACF フィールド構成、特殊なメニュー位置、固有のCF7 mailto設定 等

## 概要（要点のみ）

コーディング完了後、以下を Playwright MCP 経由で WP 管理画面に自動登録：

1. 固定ページ作成（`page-*.php` → 対応するページ）
2. ACFフィールド登録（テンプレートの `get_field()` / `have_rows()` を解析）
3. Contact Form 7（フォームありの場合）
4. メニュー登録（`wp_nav_menu()` の `theme_location` に基づく）
5. カスタム投稿タイプ / タクソノミー（`functions.php` を確認）

**実行タイミング**: ページ単位で都度実行（全ページ一括ではない）

**前提**: `.page-info/README.md` の「環境情報」に WP 管理画面URL・ID・パスワードが記入されていること。未記入なら**ユーザーに質問してから記録**。

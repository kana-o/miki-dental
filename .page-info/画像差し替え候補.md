# 画像の棚卸し（Figma からの再書き出し）

> 最終更新: 2026-09-11 / 判定は `node scripts/img-usage.cjs` ＋ 比率・解像度チェック
>
> **判定**: 素材の縦横比 と カンプの枠の縦横比 の差が3%以上 → トリミングが効いていない。
> 素材の幅 < 枠の幅×2 → 拡大表示でぼやける。

## 対応済み

Figma REST の `/v1/images`（ノードのレンダリング＝見たままの画像）で **125枚を再書き出し**した。
枠の縦横比と一致し、すべて 2x 解像度。

手順は `scripts/fig-image-nodes.mjs`（画像ノードの収集）→ 実装側の枠サイズ・x座標で
自動マッチング → `scripts/fig-render.mjs`（レンダリング書き出し）。
角丸マスクが焼き込まれるノードは png で受け取り、透明になった四隅だけ
最寄りの不透明画素で埋めてから jpg 化している（png 出力は透過をそのまま残す）。

## 付随して直した実装バグ

- `.pedprev-row__photo--wide`: 基本クラスの比率を継いで 280x262 になっていた（カンプは 280x215）
- `.pedortho-case__photo`: 490x200 で組んでいた（カンプは 464x200）。矢印も 48x118 → 36x62、
  行は中央寄せ → 左端そろえ（カンプは x=260 から）
- `.pedortho-device__row`: 中央寄せ → 左端そろえ（カンプは x=260 と x=713）

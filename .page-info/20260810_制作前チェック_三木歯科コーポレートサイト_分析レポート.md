### 中途半端な画面幅の注意箇所

PC 1600px と SP 375px の2点しか定義がなく、**768〜1200px の指定が存在しない**。以下は中間幅で破綻が想定される。

| 箇所 | 懸念 |
|---|---|
| **グローバルナビ（G-nav 738px に8項目）** | タブレット幅では文字が詰まる／改行する。何pxでハンバーガーに切り替えるか要決定 |
| **料金テーブル（1080×643 等・11個）** | 1080px固定。タブレット幅で横スクロールにするか、縮小するか、カード分解するか |
| **コンテンツ幅3種混在（1080 / 980 / 900px）** | 中間幅での縮小基準が定まらない。統一が望ましい |
| **パララックス要素（1650px幅）** | ビューポートより広い要素。中間幅での見え方が未定義 |
| **当院について「特徴」等の横並びカード** | PC横並び → SPで縦積みだが、中間幅の列数が未定義 |
| **TOP スタッフ紹介（PC 2464px / SP 3295px）** | PC/SPでレイアウトが大きく異なる。切り替え点の決定が必要 |

> **推奨**: `768px` / `1024px` の2点を追加し、`1024px以上=PC` / `768〜1023px=タブレット（PC準拠で縮小 or 2カラム）` / `767px以下=SP` とする。最終判断は要確認。
